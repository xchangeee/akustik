# Plan: measurements for later

Not scheduled yet. Pick from here when planning a session. Method and positions: [procedures/measurement-sets.md](../procedures/measurement-sets.md).

- Walk through the room with the RTA (pink PN, slow sweep of the mic) to see how uneven the bass is.
- R at different side/rear distances (SBIR dip at ~173–190 Hz).
- Duvet held behind the head to test whether an absorber is worth it.
- REW Room Simulator with the existing data, to compare with the measurements.
- Final check: play a sweep from the TV (e.g. a REW sweep file on a USB stick) to make sure no TV processing is left on.
