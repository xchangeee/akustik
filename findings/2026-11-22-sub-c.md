# Sub8 at spot C: measured, designed into EQ v3 (flat + sub) and v4 (Harman + sub)

> The Out 3 values in this file are the **first design**. Replaced the same day by a design without the 28 Hz overshoot: [2026-11-22-sub-c-28hz.md](2026-11-22-sub-c-28hz.md).

2026-11-22. Script and full output: [analysis/analyse_sub_c.py](../analysis/analyse_sub_c.py), [sub_c.txt](../analysis/output/sub_c.txt), [sub_c.png](../analysis/output/sub_c.png). Spot A not measured (skipped for now).

## Measured

- Sets `subC-seat`, `subC-dj`, `subC-corners`: 16 positions, sub only (P04, Out 3 at −10 dB).
- Sub position: back against the right wall, driver/port 0.73 m off the wall, centre 2.40 m from the speaker wall ([current-setup](../docs/current-setup.md)).
- Level tests: Out 3 at −20 dB gave only 43 dB SNR (20–120 Hz), so it went up to −10 dB (52 dB SNR). No audible hum from the sub.
- The sub reaches no deeper than the mains (steep drop below 25 Hz, its subsonic filter). It adds level at 25–35 Hz, where the mains fall off below their 29.8 Hz HPF.
- At the DJ spot, the sub has the same 31–35 Hz hole as the mains: spot C doesn't fill it.
- The script's "delay" is wrong for some sub sweeps (it picks the room build-up at ~55 ms). This doesn't affect the IRs: t=0 comes from the loopback.

## Design

- Each preset gets its own Out 3. Mains filters stay as in v1 / v2, so **sub off = today's v1 / v2**.
- Fitted to the preset's target (v1 flat, v2 Harman shelf), 25–120 Hz, seat 2/3 + DJ 1/3.
- Polarity 180° and ~6 ms delay on Out 3 came out the same in every run and for both presets.
- One PEQ band at 46–47 Hz (the sub excites the 45–50 Hz mode at the seat). 4 narrow bands gained only 0.1–0.2 dB and moved on every run.

| --- | --- | --- |
| Out 3 LPF | BW24 38.5 Hz | LR24 52.0 Hz |

| Seat bass energy 25–60 Hz | +2.1 dB | +4.6 dB |

- Every seat and DJ position gets better; only the front-right floor corner gets a bit worse.
- v3: the sub fills only the 25–35 Hz the mains are missing. v4: also lifts 45–75 Hz up to the Harman target.
- Both overshoot around **28 Hz at the seat** (the mode the model predicted for C): v3 +4 dB, v4 +4 dB above target. Fixed in the second design: [2026-11-22-sub-c-28hz.md](2026-11-22-sub-c-28hz.md).
- The `Sub.txt` files pass tracks' `rewImport` (no errors, values map back exactly).
- Live gain = test gain − 6 dB, because Out 3 sums A+B and bass is about mono. The DSP's internal headroom for that sum isn't known.
- **The amp knob only moves the mains**, so the sub is matched at one amp position per preset: each EQ's fun position ([listening](2026-11-20-listening.md#amp-volume-smsl-a300-per-eq)), v3 at 50, v4 at 45. A300: 1 dB per step (72 dB(C) at 50, 67 at 45, pink noise). Below that position the sub plays relatively louder (1 dB per step).
- Sub = for fun sessions at that amp position; everyday listening without the sub. Volume before the DSP (so the sub follows) would need a stereo volume control between TV and DSP: the TV's analog out is fixed. DSP input gain as a volume knob is out: every write goes to its EEPROM.

## On the DSP

- Written by tracks' `probe --make-preset` (P02 → slot 5, P03 → slot 6, only Out 3 and the name changed) and `--set-out3-gain 6 235`; every slot read back and compared. Dumps: `~/WPlay/tracks/measurements/make-preset/`.
- P05 "EQ v3 flat+sub", P06 "EQ v4 Harm+sub". P02/P03 unchanged (read back).

## Caveats

- The level needs a listening check. With v4 at amp 50 the sub plays ~16 dB louder than in the test sweeps. Listen for the sub's limiter or distortion at fun levels.
- tracks' docs note the device's PEQ centre frequencies can come out up to 41 cents low below 150 Hz. Only a measurement of the new presets shows that.
