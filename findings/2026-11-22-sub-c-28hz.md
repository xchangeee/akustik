# Sub at C: the 28 Hz overshoot removed (EQ v3 / v4, second design)

2026-11-22. Same data and script as [2026-11-22-sub-c.md](2026-11-22-sub-c.md): [analysis/analyse_sub_c.py](../analysis/analyse_sub_c.py), output [sub_c.txt](../analysis/output/sub_c.txt), [sub_c.png](../analysis/output/sub_c.png).

## Problem

- First design: seat **+3.7 dB (v3) / +3.9 dB (v4) above target at 28 Hz**, the 28.6 Hz length mode that spot C drives.
- The deepest bass leaks through the building most, so that band should stay at target.
- The optimiser kept the peak on purpose: the DJ spot is at or below target there, and the 2/3 seat + 1/3 DJ rms liked that trade. A free second PEQ band didn't help for the same reason.

## Fix (leak guard)

- Design cost: overshoot above target at the seat below 35 Hz counts extra (weight 2 on its squared rms).
- One extra band on Out 3: cut only, 25–32 Hz.
- Weights 4 and 8 tried: same 28 Hz result, more change elsewhere. Weight 0 without the band reproduces the first design exactly.

## Result (dB vs target, 1/6 oct power average)

| | v3 first | v3 now | v4 first | v4 now |
| --- | --- | --- | --- | --- |
| Seat 28 Hz | +3.7 | **+0.4** | +3.9 | **+0.6** |
| Seat 31.5 Hz | +1.5 | +0.4 | +1.4 | +0.2 |
| DJ 28 Hz | −0.3 | −3.6 | +0.4 | −3.1 |
| rms 25–120 Hz (seat 2/3 + DJ 1/3) | 2.15 | 2.20 | 2.56 | 2.63 |
| Seat bass energy 25–60 Hz vs mains alone | +2.1 | +1.1 | +4.6 | +3.6 |

- Every seat and DJ position is still better than with the mains alone; the front-right floor corner is still a bit worse.
- The price: the DJ spot loses ~3 dB at 28 Hz (now below target).
